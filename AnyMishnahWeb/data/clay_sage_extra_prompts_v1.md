# Three more clay sages, for rows with many students (2026-10-30)

Why: when a sage has many students, the box shows every picture it has and then repeats faces. There are 7 figures (main, 3 teachers, 3 students); these add three more middle-aged men (student-4, -5, -6), so there are 6 student faces. Each is made in GREEN first (the students' colour), then recoloured to GOLD and BLUE from that picture, exactly as before (3 figures x 3 colours = 9 pictures).

What is different from the first set (checked against the 7 we have):
- Every one of them has a HEAD COVERING from the start (the bare-headed first versions had to be redone). Each covering is a different kind, so they can be told apart at a glance.
- Different faces, ages (about 35, 50, 55) and builds, different poses (the existing ones have a scroll, a hand on the chest, a raised finger, clasped hands, open hands), and a slightly different skin tone, so the row looks like different people.
- Same look as the rest: plasticine clay, plain wool tunic and plain wool cloak, rope belt, nothing tailored or modern; no stripes or patterns anywhere; no letters or numerals; one figure; plain flat pure-white backdrop; square, head to the waist.

Design choices, not from any source (for review): the ages, beards, skin tones, poses and the three kinds of head covering.

How to use: for each figure, start a NEW Gemini chat, paste the PASTE block, and save the result as `student-4-green` (and so on). Then, in the same way as for the first set, use the recolour block for each figure (attach its green picture) to get gold and blue. Send me the pictures; I cut out the backgrounds and wire them in. Name each file `student-N-colour`, so I can drop it in the right place.
