# Transliteration standard (author-approved 2026-09-24; prefix and apostrophe rules revised the same day)

For everything generated for learners: outline headings, gists and bullets, key terms, the master
glossary. (The shiur essays are a later, separate job — see TODO.md.) The outline prompt carries
these rules; `transliteration_exceptions.json` holds the conventional spellings that override them.

| Hebrew | Standard | Examples |
|---|---|---|
| כ ך without dagesh | **kh** | chinukh, halakhot, melakhah, berakhah, lekhem, Tanakh |
| ח chet | **ch** | chatzer, Chagigah, chinukh, nitu'ach |
| צ | tz | chatzer, mitzvah |
| ת without dagesh | t (never s) | Shabbat, Tosafot |
| ק | k | kinyan, Kohen |
| Final ה | **-ah** | Chagigah, mitzvah, melakhah, Mishnah |
| א / ע between vowels | apostrophe **only where the two vowels would otherwise run together** | re'iyah, Mo'ed, tanna'im, ne'emru, nesi'im, ma'ah — but **nituach** (u or i before a *different* vowel is read as two syllables anyway, like "pursuant") |
| Prefixes ו ה ב ל מ ש כ | **apostrophe, never a dash** (a dash reads as academic and off-putting) | ve'nituach, kelalot u'feratot, ha'mishtameret, be'Sinai, le'Rabbi |
| Dagesh chazak | double only where conventional | Shabbat, Kiddushin, tefillin |
| Sheva na | e | berakhah, kelalot |

**Exceptions** (established spellings win over the rules): see `transliteration_exceptions.json`.
Always exceptions: tractate names as the app lists them (Hullin, Eiruvin, Taanit, Meilah, Moed
Katan…), and sages' names in common English usage (Rav Chisda, Abaye, R. Yochanan).
